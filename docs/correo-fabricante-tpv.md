**Asunto:** Integración oficial para lectura de ventas – documentación y entorno de pruebas

Hola, [nombre del contacto]:

Como partners de [nombre del TPV], estamos preparando un servicio de previsión de ventas
para bares y restaurantes que usan vuestro programa. El servicio **solo necesita leer**
las ventas: **nunca escribirá en la base de datos del TPV**.

Para empezar, os pedimos:

1. **La documentación de la integración oficial** para leer datos: cómo se accede
   (librería, servicio web, vistas de base de datos u otro sistema) y qué datos ofrece.
2. **Acceso al entorno de pruebas**, con datos de ejemplo.
3. Confirmación de que podemos leer, **solo en modo lectura**, esta información:
   - líneas de venta con fecha, hora, artículo, cantidad, precio y familia
     (SalesOrderLine),
   - carta y precios (Article, ArticleTariff),
   - familias (TurnOverGroup, MainTurnOverGroup),
   - mermas y stock.
4. Saber **qué campos contienen datos personales** (por ejemplo, nombre del camarero,
   del cliente o datos de facturas), para no enviarlos nunca fuera del local.
5. Si un negocio con **varios locales** tiene una base de datos por local o una común.
6. El **procedimiento para que vuestro técnico instale** un pequeño programa nuestro en el
   ordenador del local: requisitos, versiones de Windows habituales y si tiene coste.
7. Si hay alguna **condición o limitación** del acuerdo de partners que debamos conocer.

Nuestro programa solo enviará, cifradas y a servidores en la Unión Europea, las ventas
agrupadas por artículo, día y hora, siempre con la autorización del local.

Quedamos a vuestra disposición para una llamada si os resulta más cómodo.
